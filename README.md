# 课夹 · Windows 文件夹资料库

课夹是在 Windows 本机运行的资料管理网站。选择移动硬盘或目录后，左侧按实际文件夹名称生成资料库栏目；点击栏目查看文件，再将资料投递到对应文件夹，也可以按文件名自动分类。

## 下载与分享

[下载最新 Windows 分享包](https://github.com/qinyin1337/kejia-windows/releases/latest) · [查看源代码](https://github.com/qinyin1337/kejia-windows)

本版分享包为 [`kejia-windows-v1.5.0.zip`](https://github.com/qinyin1337/kejia-windows/releases/download/v1.5.0/kejia-windows-v1.5.0.zip)。解压后按下方步骤运行，它在各自电脑上读写所选目录，每个人的文件与设置分别保存在本机。

## 开始使用

需要 Windows 10/11、可读写的硬盘，以及 Node.js 20 或更新版本。无需百度网盘开发者账号，无需安装第三方 Node 套件。

1. 解压分享包或下载本仓库，将程序放在电脑上的固定文件夹。
2. 安装 Node.js，接入移动硬盘，双击 `start.cmd`。
3. 保持启动窗口打开，用 Edge 或 Chrome 打开 <http://127.0.0.1:3000/>。
4. 点“选择浏览位置”，粘贴完整文件夹路径（例如 `E:\学习资料`）并保存；也可点“打开系统选择窗口…”浏览整个硬盘或目录。系统窗口选好后先填入路径，点击“保存位置”才切换。
5. 左侧资料库自动读取所选目录下的一级文件夹；点击一个栏目，查看文件夹内容。没有栏目时，点“＋”先新建文件夹。
6. 在投递区域选择文件、导入文件夹或拖入文件，默认智能识别文件名并匹配栏目；确认每个文件的目标后，点“开始投递”。

也可以在项目目录的 PowerShell 中运行 `node server.mjs`。关闭启动窗口后文件操作会停止，下次双击 `start.cmd` 即可继续。

## 资料库栏目

- 栏目名称来自硬盘上的真实文件夹，按照名称排序，支持鼠标滚轮在左侧独立滚动。
- 点击栏目打开对应文件夹，投递区域显示目标完整路径。进入下级目录后，投递到当前下级目录。
- 点击资料库旁的“＋”新增栏目，会在所选浏览根目录创建同名文件夹，并打开新栏目。
- 页面中的“新建文件夹”在当前目录创建子文件夹。
- 文件夹重命名后栏目同步更新；网页每 15 秒读取栏目，也可以点击“刷新”同步外部改动。
- 隐藏的点开头目录、受保护的系统目录及符号链接不在列表中。栏目显示所选根目录的一级文件夹，下级目录通过主页面进入。

“硬盘总览”返回所选硬盘或目录的根目录。“选择浏览位置”可以切换盘或目录，选择会自动保存。

## 存储位置选择（1.5.0）

点击“选择浏览位置”或“设置硬盘目录”会立即打开页面中的路径输入框，不等待旧硬盘路径检查或系统选择窗口。可以复制 Windows 文件资源管理器地址栏中的完整路径并保存，包含空格或带引号的路径也能识别。

“打开系统选择窗口…”改用现代 Windows 文件夹对话框，包含地址栏、搜索与快速访问，从“此电脑”开始，不预先定位可能离线的旧硬盘。选择结果只填入输入框，保存后才切换；关闭页面对话框会终止该选择进程。系统窗口卡住时仍可填写路径并保存，超过五分钟会自动终止等待并提示直接输入。

设置归档目录只保存位置，不再自动递归扫描。需要更新索引时，在“归档记录”点击“扫描归档目录”。选择浏览位置只读取一级栏目和当前页文件。路径保存时仍需确认实际目录存在且可访问，硬盘本身响应慢时这一步仍可能需要等待。

## 智能识别文件名并分类（1.5.0）

默认开启。加入文件时读取最新的一级资料库栏目，支持名称匹配、常见课程简称、中英文主题别名、关键词顺序变化，以及较长主题的单字错误：

| 文件名 | 已有栏目 | 自动目标 |
| --- | --- | --- |
| 数学_期中试卷.pdf | 数学资料 | 数学资料 |
| 高数复习.pdf | 数学、高等数学资料 | 高等数学资料 |
| English作业.docx | 英语课件 | 英语课件 |
| linear_algebra习题.pdf | 线性代数 | 线性代数 |
| 工程软件复习.pdf | 软件工程资料 | 软件工程资料 |
| 软件工桯讲义.pdf | 软件工程资料 | 软件工程资料（提示核对近似名称） |
| employment_agreement.pdf | 合同资料 | 合同资料 |

- 忽略英文大小写、全角半角及空格、下划线等分隔符；识别栏目开头带分隔符的数字编号，以及“资料”“课件”等常用结尾。
- 内置常见主题别名，例如高数／高等数学、线代／线性代数、English／英语、AI／人工智能、计网／计算机网络。文档类型别名可识别试卷／考试、协议／合同等；能确定课程主题时优先课程栏目。
- 关键词可以换序；四个字符以上的主题支持单字替换、缺漏、多字或相邻两字交换。短词和含数字的主题不进行错字猜测，避免把“数学”当成“化学”或混淆年份。
- 这是本机内置别名与近似识别，不调用在线 AI，不读取文档内容。没有内置的别名或文件名信息不足时，仍需手动选择；不会根据扩展名或导入目录名称推测课程，也不会把 JavaScript 匹配为 Java。
- 比较范围是所选硬盘或目录下的**一级文件夹**，不递归扫描整块硬盘。下级文件夹可先打开再投递，或在队列中选择加入文件时的目录。
- 多个不同主题（如“数学English合集.zip”）或无法区分的栏目仍提示“多个匹配”。无可靠匹配时提示选择目标。所有待投递文件都有目标后才能开始，不会默认投递到根目录。
- 队列会显示识别依据。可逐个修改目标，“重新自动匹配”使用最新栏目并保留手动选择。
- 关闭自动分类后，尚未手动指定的文件回到加入队列时的目录；手动指定的目标保留。再次开启时重新匹配。
- 超过 30 个文件时队列分页，可逐页查看和调整。“查看待选择”跳到尚未指定目标的文件。批量识别分段执行，期间页面可继续响应。

智能匹配只填写目标位置，点“开始投递”后才实际复制文件。

## 投递文件

文件由本机服务直接复制到每个文件确认的目标文件夹，保留原件。每个待投递文件可选择不同的目标栏目。文件重名时自动追加序号，避免覆盖。导入文件夹时，选中的各个文件会放入目标目录。

队列保留加入时的硬盘和目标位置。切换浏览位置后，需要返回原位置投递原队列，或移除旧队列再选择新文件。不存在的目标目录会提示重新选择，不会自动创建错误的目标目录。

复制不先缓存在内置盘，应用未设置单个文件大小上限，实际大小及容量受硬盘格式和可用空间限制。

## 浏览、重命名与定位

目录支持分页，每页 100 个项目，搜索当前文件夹名称。点击文件夹逐层进入，点击文件名称或“定位”在 Windows 文件资源管理器中显示文件。

重命名和新建会直接写入硬盘。重命名文件时请保留正确扩展名。同名目录或文件会提示更换名称。当前索引归档文件夹及它的上级目录需先更换归档位置才能重命名。

## 归档记录

资料库按实际目录浏览和投递，可以独立使用。顶部“设置硬盘目录”用于选择需要建立搜索索引的归档范围；快速访问“归档记录”查看该范围的索引，手动点击“扫描归档目录”建立或同步索引。

投递到索引范围内的文件会同步更新记录；投递到其他文件夹的文件在对应资料库栏目中查看。“查看归档目录”可以返回已设置的索引范围。

硬盘拔下后已有索引仍保留，实际浏览、修改和投递需要重新接入。盘符改变后重新选择目录。

## 百度网盘与分享

点击侧栏“百度网盘”，在新标签页打开网盘网页。备份文件时，在网页或 Windows 客户端中上传对应文件夹。

分享 Windows 程序包即可让别人独立使用，对方安装 Node.js、运行 `start.cmd` 并选择自己的硬盘。分享包与仓库均不包含个人文件、路径设置或资料索引。

## 本机设置

服务默认只监听本机地址。设置及索引保存在程序目录的 `.data/`，不提交到 Git。可复制 `.env.example` 为 `.env` 预设 Windows 归档路径，网页设置优先。

系统窗口使用 [Windows IFileOpenDialog](https://learn.microsoft.com/windows/win32/api/shobjidl_core/nn-shobjidl_core-ifileopendialog)，由本机服务调用 Windows PowerShell，程序附带 `windows-folder-picker.ps1`，请保留此文件。应在登录桌面的 Windows 用户会话中运行程序。

## 更新已有安装

先关闭旧版启动窗口，备份原程序目录，再将新版程序文件覆盖到原目录。保留 `.data/`（本机目录设置和索引）及自建 `.env`；新版分享包不包含或覆盖这些文件。重新运行 `start.cmd`，浏览器刷新后使用。资料原件仍在原硬盘目录，无需迁移。
